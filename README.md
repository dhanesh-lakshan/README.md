An intelligent tourism platform designed to improve travel experiences in Sri Lanka through AI-powered travel planning and local tourism information.

**Key Features**

- 🧠 AI-powered trip planning.
- 🏝️ Destination and hidden gems discovery.
- 🏨 Travel accommodation and vehicle information.
- 📍 Tourism content and location management.
- 📊 Admin dashboard and backend management.
- ☁️ Cloud deployment and API integration.

**Technologies**

`React` `Node.js` `Firebase` `AWS` `REST APIs`

**My Contributions**

- Backend development and API implementation.
- Admin panel development.
- Cloud deployment and infrastructure setup.
- Database design and API testing using Postman.
